# GltuSchedule

> ## 🎓 专为 **桂林旅游学院（GLTU）** 同学做的课程表 Android 客户端
> **版本 0.10beta** · 作者 **木下葵**

GltuSchedule 是一个**全程本地运行**的课程表 App，围绕桂林旅游学院教务系统的真实页面结构开发：
一键导入本校课表、按课程自动配色、中国大陆法定节假日自动屏蔽、桌面小部件、
上课前系统通知提醒、一键同步到手机日历。

**没有服务器、没有账号体系、没有埋点。** 所有数据只存在你自己的手机里（Room 本地数据库），
课表导入靠 App 内置浏览器登录**桂林旅游学院教务系统**后直接解析页面，不经过任何第三方。

> 因为是为 GLTU 定制，它内置了本校专属的细节：13 个小节的作息时间表、
> 房号→教学楼映射（旅勤楼/旅思楼/旅博楼/旅齐楼）、WebVPN 与 6 个校内教务入口、
> 以及针对强智「教学管理信息服务平台」页面结构写的解析器。

## ✨ 功能

### 课表

- **周视图网格**：左侧节次轴（节次号 / 上课时间 / 下课时间），7 天课程彩块，跨节次自动合并
- **日视图列表**：单天课程，左侧时间轴，显示课程名 / 地点 / 教师 / 第 X-Y 节
- **自适应手机宽度**：按屏宽算出列宽，不需要横向滚动
- **周次切换**：点「第 N 周」下拉选周，支持 1–30 周
- **单双周 / 不规则周次**：完整支持教务系统的 `4-5周,8周,11-13周(单),14-16周` 这类写法
- **点课程**：查看详情（教师 / 地点 / 时间 / 周次 / 学分），可编辑或删除

### 课表导入（三种方式，可混用）

| 方式 | 说明 |
|---|---|
| **① GLTU 教务系统导入（推荐）** | App 内嵌浏览器打开**桂林旅游学院教务系统**，你自己登录并进入课表页，点「确定导入」自动解析。针对强智「教学管理信息服务平台」的列表视图 / 表格视图 / div 栅格多种页面结构编写，并自动识别学期名与当前周次 |
| **② 手动添加** | 自己录入课程名 / 地点 / 时间 / 周次 |
| **③ 课表分享码** | 生成一段 Base64 分享码（微信/QQ 直接发），同学粘贴即可导入，**不规则周次也能完整还原** |

> 校外访问教务系统需要**校园网**或学校的 **WebVPN**（App 内置了 WebVPN 与 6 个校内入口 `jwcweb1~6.gltu.cn`）。

### 中国大陆节假日屏蔽

- **数据源**：[holiday-cn](https://github.com/NateScarlet/holiday-cn) —— 由《国务院办公厅关于节假日安排的通知》生成，
  只包含**中国大陆**法定节假日（元旦 / 春节 / 清明节 / 劳动节 / 端午节 / 中秋节 / 国庆节）与**调休补班日**，
  不含任何其他国家或地区的节日。备用源为 timor.tech，都失败时回退内置数据。
- **三个互相独立的开关**：`屏蔽法定节假日` / `屏蔽学校假期（校运会·寒暑假）` / `屏蔽日常周末`
- **补班日例外**：调休上班的周末不受任何开关影响，一律照常上课
- **日期显示与屏蔽解耦**：日期行上的假期名（校运会 / 国庆节 / 寒假…）是日历事实，**始终显示**，
  不会因为关掉开关而消失（只是从红色变灰色）
- **自动同步**：打开 App 时检查一次；每天凌晨 3:30 后台自动更新；11/12 月若还没拿到次年安排则每 3 天重试一次

### 上课提醒

- **提醒时间可选 1–60 分钟**（滚轮选择，可多选，如课前 30 / 10 / 5 分钟各提醒一次）
- **未来 30 天滚动排期 + 每日自动续排**，App 不打开也能持续提醒
- 节假日被屏蔽的当天不提醒
- 改动设置后立即重排，不留旧闹钟

### 桌面小部件（适配小米 / HyperOS）

- 三种规格：**2×2 / 4×2（可拉伸）/ 4×4**，用 `RemoteViews` 实现，兼容性最好
- 标题与课表页一致：`第 6 周 · 10月6日 周二`（假期显示假期名）
- 每条课程：课程配色条 + 课程名 + 起止时间 · 上课地点（含楼栋）+ 教师 + 第 X-Y 节

### 教室楼栋自动识别

按学校房号规则从 4 位房号推导教学楼 / 楼层：

| 位 | 含义 |
|---|---|
| 首位 | 1=旅勤楼　2=旅思楼　3=旅博楼　4=旅齐楼 |
| 次位 | 楼层 |
| 后两位 | 教室号 |

例：`3217` → **旅博楼 2 楼 17 号教室**；课表格子显示 `旅博楼 3220（阶7教室）`

### 个性化

- **个性化壁纸**：选图后进入整屏裁切（双指缩放 / 拖动，所见即所得），按屏幕比例输出，**保证铺满背景**
- **主题**：跟随系统 / 浅色 / 深色（Material 3 动态取色）
- **每周起始日**（周一/周日）、**课表显示节数**（6/8/10/12/13 节）

### 同步到系统日历

一键把整学期课表写进手机日历：周次连续的课写成「每周重复」事件，
单双周等不规则周次逐次写入，每条默认提前 10 分钟提醒。
重复点击会先清理上次同步的条目，不会产生重复。

### 隐私

- 全程本地：Room 数据库 + SharedPreferences，**没有自建后端**
- 不申请存储权限（壁纸复制到应用私有目录）
- 联网只用于两件事：**登录学校教务系统抓课表**、**同步中国大陆节假日数据**

### ⚙️ 安装后建议设置

- 系统要求：**Android 8.0（API 26）及以上**
- 首次启动请允许「通知」权限，否则上课提醒无法弹出
- **小米 / Redmi**：为保证提醒准时，建议到
  `设置 → 应用管理 → GLTU课表 → 省电策略 → 无限制`，并允许自启动
- Android 12+ 请到 `设置 → 应用 → 特殊应用权限 → 闹钟和提醒` 允许本应用，
  否则提醒会退化成不精确闹钟（App 内也会提示「去授权精确闹钟」）

## 🔨 从源码构建

```bash
git clone https://github.com/<你的用户名>/GltuSchedule.git
cd GltuSchedule/app-android
./gradlew assembleDebug          # Windows: gradlew.bat assembleDebug
```

产物：`app-android/app/build/outputs/apk/debug/app-debug.apk`

- **Android Studio**：直接打开 `app-android` 目录（不是仓库根目录）
- 环境要求：**JDK 17** + Android SDK **API 35**（build-tools 35.0.0）
- 跑单元测试：`./gradlew testDebugUnitTest`（**62 个用例**）

详细打包步骤（含 Android Studio 汉化）见 [docs/构建与打包.md](docs/构建与打包.md)。
