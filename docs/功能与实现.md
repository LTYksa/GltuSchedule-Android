### 节假日屏蔽（已实装，可联网同步）

> ⚠️ 只识别 **中国大陆** 法定节假日：元旦 / 春节 / 清明节 / 劳动节 / 端午节 / 中秋节 / 国庆节，
> 以及国务院办公厅公布的**调休补班日**。**不含任何其他国家或地区的节日**。

- **数据源**（按优先级自动回退，结果本地缓存）：

  | 优先级 | 来源 | 说明 |
  |---|---|---|
  | 1 | **holiday-cn 数据集** | 由「国务院办公厅关于节假日安排的通知」生成，每条数据带政府文件链接 |
  | 2 | timor.tech 节假日接口 | 备用源，同样是中国大陆法定节假日 |
  | 3 | 内置数据 | 两个源都取不到时离线兜底 |

- **自动同步时机**（无需手动干预）：

  | 时机 | 触发条件 |
  |---|---|
  | 打开 App | 从未同步过，或距上次成功同步 ≥ 7 天 |
  | **每天凌晨 3:30 后台维护** | 同上；**App 不打开也会跑**（`DailyMaintenanceReceiver`，同时负责补齐未来 30 天上课提醒） |
  | 11/12 月加密重试 | 已同步但**还没拿到次年数据**时，每 3 天重试一次（国务院办公厅通常在前一年 11 月发布次年安排） |

  同步失败不会更新"上次同步时间"，所以下次会自动重试；失败时自动回退内置数据，不影响屏蔽功能。

- **可在设置页直接查看已收录的假期清单**（名称 + 日期区间 + 类型），自己核对是不是中国大陆的节日。
- **三个互相独立的屏蔽开关**（可任意组合，互不影响）：

  | 开关 | 覆盖范围 |
  |---|---|
  | 屏蔽法定节假日 | 元旦 / 春节 / 清明节 / 劳动节 / 端午节 / 中秋节 / 国庆节 |
  | **屏蔽学校假期** | **校运会 / 寒假 / 暑假（来自 GLTU 校历）** |
  | 屏蔽日常周末 | 周六、周日 |

- **补班日例外**：调休上班的周末（如"国庆节后补班 10/10"）**不受任何开关影响**，一律照常上课。
- **日期显示与屏蔽解耦**：日期行上的假期名（校运会 / 国庆节 / 寒假…）是**日历事实，始终显示**，
  不会因为关掉对应开关而消失。开关只决定"课程是否隐藏"，显示上的区别是：

  | 状态 | 日期下标 | 日期方块底色 |
  |---|---|---|
  | 已屏蔽 | 假期名（红色、加粗） | 浅红底 |
  | 未屏蔽（开关关掉） | 假期名（灰色） | 正常 |

- **生效范围**：课表网格（屏蔽时当天课程隐藏）、日视图、桌面小部件、上课提醒。
- 假期清单在设置页**按类别分组**显示，每条还标注当前开关下的"已屏蔽 / 未屏蔽 / 照常上课"状态，方便核对。

### 自定义壁纸裁切（推倒重写版）

`☰ → 个性换肤 → 选择壁纸` 后进入**整屏裁切界面**：

- **裁切框 = 整个屏幕**：你在这一屏看到的就是设置成壁纸后的效果，没有"框外内容"的歧义
- 双指缩放（最大 8 倍）、单指拖动；缩放下限 = `max(屏宽/图宽, 屏高/图高)`，
  **图片任何时刻都盖满屏幕，不会露黑边**
- 底部「铺满屏幕」一键回到初始铺满状态
- **输出比例 = 屏幕比例**，所以课表页用 `ContentScale.Crop` 渲染时不会被二次裁掉 → **壁纸一定铺满背景**
- 输出分辨率跟屏幕一致（限制 720–1440 宽），存私有目录，无需存储权限
- 相机竖拍照片会自动应用 EXIF 方向（API 28+ 走 `ImageDecoder`），不会躺倒

> 上一版的实现有两个 bug，这次已修正并加了单元测试锁死：
> ① 换算系数 `k` 误用了"图片宽度×缩放"而不是视口宽度；
> ② `postTranslate` / `postScale` 顺序反了，导致位移被二次缩放。

### 壁纸在课表页的显示

- 壁纸**铺满整屏**（含顶栏与日期行），不做半透明淡化
- 覆盖一层**渐变蒙层**（顶部 0.66 → 中部 0.40 → 底部 0.32），保证花哨照片上文字依然清晰
- 有壁纸时课程格子底色自动加实（0.13 → 0.34），课程色块不会被照片干扰

### 一键同步课表到系统日历

`设置 → 同步到手机日历 → 一键同步课表到日历`（首次会申请日历读写权限）：

- 周次连续的课 → 写成**一个「每周重复」事件**（条目少、干净）
- 单双周 / 不规则周次（如 `4-5周,8周,11-13周(单)`）→ **逐次写入**，保证准确
- 每条事件带地点（含楼栋）、教师、周次说明，并默认**提前 10 分钟**提醒
- 重复点击会**先清理上次同步的条目**再写，不会产生重复

### 上课提醒时间（滚轮选择）

`设置 → 上课提醒 → 选择提醒时间`：**滚轮上下滑动选分钟数（1–60）**，
点「添加」加入提醒列表（点标签可删除），保存后**立即重排闹钟**。
提醒采用「未来 30 天滚动排期 + 每日自动续排」，改设置不会残留旧闹钟。

> **闹钟请求码必须包含"哪门课"**：`PendingIntent` 的匹配用 `Intent.filterEquals`，
> 它**不比较 extras**。若请求码只有「日期 + 提前分钟数」，同一天同一档提醒的多门课会共用
> 同一个 PendingIntent，后一节课的闹钟会把前一节**顶掉**（表现为"一天只有最后一节课会响"）。
> 现在请求码 = 日期(9位) + 课程槽位(12位) + 分钟(6位)，并把每次排入的码存进 prefs，
> 下次精确清理——既不撞车，也不用遍历整个码空间。

> Android 12+ 若未授予「闹钟和提醒」权限，会退化成不精确闹钟（可能延迟很久）。
> 设置页会检测并在「上课提醒」卡片里提示「去授权精确闹钟」。

### 课表格子可读性

- 字号按列宽取 **8.5–10sp**（不再缩到 6sp 的看不清尺寸）
- 文字用**加深色**（课程色 ×0.62），浅底上对比更强；格子加细边框提升辨识
- 空间不足时按优先级取舍内容：**课程名 > 地点 > 教师**（而不是把字缩小到看不清）
- 左侧时间列同时显示**上课时间与下课时间**（`08:20 ─ 08:50`）

### 教室楼栋自动识别

按学校房号规则从房号推导**教学楼 / 楼层 / 教室号**（见下），课表格子与日视图显示短标签，详情弹窗显示完整信息：

| 位 | 含义 |
|---|---|
| 首位 | 1=旅勤楼　2=旅思楼　3=旅博楼　4=旅齐楼 |
| 次位 | 楼层（数字几代表几楼） |
| 后两位 | 教室号 |

例：`3217` → 旅博楼 二楼 17 号教室；`1510` → 旅勤楼 五楼 10 号教室。

- 课程详情：`雁山校区 · 旅博楼 2 楼 · 3220（阶7教室）`

## 二、获取课表的三种方式

### ⭐ 推荐：内嵌浏览器导入（最不容易失效）

`设置 → 获取课表 → ③ 教务系统导入`

1. 选择教务系统入口（**校外请选 `v.gltu.edu.cn`（学校 WebVPN）**，校内可选 `jwcweb1~6.gltu.cn`）；
2. 点「进入教务系统」，在 App 内的浏览器里**像平时一样正常登录**
   （验证码、密码加密、统一认证、WebVPN 全部由网页自己处理，App 不需要知道学校的登录协议）；
3. 手动进入「个人课表查询 / 课表查询」，把学期选对，然后点底部「确定导入」；
4. 确认对话框 → 点「确定导入」→ App 读取当前网页并解析；
5. 设定「当前是第几周」，单双周与不规则周次即可正确显示。

> 实现：`ui/import/WebImportScreen.kt`（WebView，含同源 iframe 与 `window.open` 接管）
> + `import/WebTimetableParser.kt`（多策略解析）。

### ① 手动添加课程
课表页右上角 **+**，自己录入课程名/地点/星期/节次/周次，颜色自动分配。

### ② 课表分享码
`设置 → 获取课表 → ② 课表分享码`：导出成一段码发同学，对方粘贴即可导入。全程本地。

> 已按你的要求**删除「自动登录导入（实验）」**（连同 app.do / jsxsd 逆向导入相关代码一并移除）。

## 三、快速开始

1. **打包**：见 [README-构建与打包.md](./README-构建与打包.md)（含 Android Studio 界面汉化步骤）。
2. **导入课表**：装好 APK → 首次打开允许通知 → 底部「设置」→「③ 教务系统导入（推荐）」→ 进入教务系统登录后进入课表页 → 点「确定导入」。
3. **桌面小部件**：长按桌面 → 添加小部件 → 搜「GLTU 课表」→ 选 2×2 / 4×2 / 4×4 任一规格。
4. **上课提醒**：默认课前 30 分钟 + 10 分钟各提醒一次；可在「设置 → 上课提醒 → 选择提醒时间」用滚轮改成 1–60 分钟之间的任意组合。小米手机需到系统设置允许自启动、省电策略选「无限制」。
5. **同步到日历**：「设置 → 同步到手机日历」一键把课表写进系统日历（首次需授予日历权限）。

## 四、技术要点（给开发者）

- 版本组合：AGP 8.6.1 + Gradle 8.7 + JDK 17 + Kotlin 2.0.21 + KSP + compileSdk/targetSdk 35 + minSdk 26 + Compose BOM 2024.10 + Room 2.6.1。
- 教务系统：强智科技「教学管理信息服务平台 V8.0」，**不是正方**。登录 `encoded = Base64(账号)%%%Base64(密码)`（网页端），移动端 `app.do` 明文密码无验证码。
- 校外访问前置风险：`jwcweb1~6.gltu.cn` 校外被墙，需校园网或 WebVPN（详见 `REFERENCE.md` / 侦察报告 `D:\dshcj\gltu-recon-report.md`）。
