# GLTU 课表 — 打包与汉化指南（Android Studio）

> ✅ 本项目已在本机用 Gradle 8.7 + JDK 17 + Android SDK 35 完成真实构建验证，`assembleDebug` 成功产出 APK。

## 一、你要准备的东西

1. **Android Studio**（最新稳定版，如 Koala/Ladybug 或更新）
   - 官方下载：https://developer.android.com/studio （Windows 版，约 1.2 GB）
   - 安装时一路 Next 即可，Android Studio **自带 JDK（JBR）**，无需单独装 Java。
2. **Android SDK 35**：首次打开项目时会自动提示安装缺失的 SDK，点 **Install missing SDK** 即可（需要联网）。
3. **网络**：首次构建需下载 Gradle 与依赖；项目已配置阿里云镜像加速（见 `settings.gradle.kts`），国内网络也较快。

## 二、用 Android Studio 打开项目

1. 打开 Android Studio。
2. 欢迎页点 **Open**（或菜单 File → Open）。
3. 选择目录 **`D:\dshcj\gltu-schedule\app-android`**（含 `settings.gradle.kts` 的那一层）。
4. 首次会弹出信任提示，点 **Trust Project**。
5. 右下角等 **Gradle Sync** 完成（首次下载依赖，可能要几分钟）。
6. 若提示安装 SDK 平台 35，点 **Install missing SDK**。

## 三、汉化 Android Studio（界面变中文）

> 汉化不影响任何功能，装的是 JetBrains 官方中文语言包。

1. 顶部菜单：**File → Settings**（快捷键 `Ctrl + Alt + S`）。
2. 左侧选 **Plugins**。
3. 点顶部 **Marketplace** 标签。
4. 搜索框输入 `Chinese`，找到 **Chinese (Simplified) Language Pack / 中文语言包**（作者 JetBrains）。
5. 点 **Install**。
6. 右下角提示 **Restart IDE** → 点 **Restart**，重启后界面即中文。

> 补充：若在未打开项目的欢迎页，左侧直接有 **Plugins**，进去同样搜 `Chinese` 安装重启即可。

## 四、打包成 APK（装到手机）

### 方式 A：菜单一键打包（最简单，推荐）

1. 确保 Gradle Sync 已完成（没有红色报错）。
2. 顶部菜单：**Build → Build Bundle(s) / APK(s) → Build APK(s)**。
3. 等右下角进度条跑完。
4. 弹出通知后点 **locate**，定位到：
   `app/build/outputs/apk/debug/app-debug.apk`
5. 把这个 APK 传到手机安装。

### 方式 B：Gradle 面板打包

1. 右侧边栏点 **Gradle**（小象图标；没有就 View → Tool Windows → Gradle）。
2. 展开 `app → Tasks → build`。
3. 双击 **assembleDebug**。
4. 产物路径同上。

## 五、装到小米手机

1. 把 `app-debug.apk` 传到手机（微信文件传输/数据线/网盘均可）。
2. 点开 APK，若提示「禁止安装未知来源」，按提示进 **设置 → 隐私保护 → 特殊权限 → 安装未知应用**，允许当前文件管理器。
3. 装好后**首次打开允许通知权限**（否则上课提醒无效）。
4. 小米省电策略会杀后台：**设置 → 应用设置 → 应用管理 → GLTU课表 → 省电策略 → 无限制**，并开启**自启动**，否则通知会延迟。

## 六、命令行构建（可选，供参考）

```powershell

```

## 七、常见问题

| 现象 | 处理 |
|---|---|
| Gradle Sync 卡住/超时 | 检查网络；项目已配阿里云镜像，重试即可 |
| 提示 compileSdk 35 未找到 | SDK Manager 安装 Android 15 (API 35) 平台 |
| 提示 JDK 版本不符 | File → Settings → Build Tools → Gradle → Gradle JVM 选 17 |
| 汉化后菜单找不到 | 重启 IDE；仍无效则卸载语言包重装 |
| 桌面小部件找不到 | 装好 App 后，长按桌面 → 添加小部件 → 搜「GLTU」 |
| 导入提示登录失败 | 优先用「App 接口」；校外网络需连校园网或 WebVPN；网页版需手输验证码 |
